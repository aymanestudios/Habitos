# Supabase

Aquí vivirá todo lo del servidor.

- `migrations/`: cambios de la base de datos en archivos SQL numerados (`0001_...sql`, `0002_...sql`). Se crean en la Fase 1 con las tablas de hábitos, XP y perfiles, siguiendo `docs/AJUSTES.md`.

En la Fase 0 solo creas el proyecto en supabase.com y copias su URL y su clave pública en `.env.local`.
